# Support

## Read first

Read the user guide first: `docs/USER-GUIDE.md`. It tells you how to install the server, add an account and use the tools.

Read the developer guide if you want to build or change the code: `docs/DEVELOPER-GUIDE.md`.

## Report a bug or ask a question

Open an issue at https://github.com/amsys/mailbag-mcp/issues.

Include this data in the issue:

- The output of `mailbag-mcp version`.
- The provider of the account: IMAP/SMTP, Outlook, Gmail or JMAP.
- The related lines of `server.log`. Before you copy them, look for secrets. Remove each token, password and mail address.

## Report a security problem

Do not open a public issue for a security problem. Send a mail to dev@amsys.cz.
